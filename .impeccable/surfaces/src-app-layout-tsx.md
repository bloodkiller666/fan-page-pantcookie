# Surface brief: site shell and all pages (redesign)

Scope: whole site. Modes: Home = Persuade; Games, Multimedia = Experience; Chat, Mensajes = Operate; About, Legal = Read; Admin = Operate.
Direction pinned by the user (no random roll): physical arcade cartridge world, existing palette kept, geometric futuristic display type, very gamer, system first then page by page.

## Direction contract

THESIS: The site is a console and every section is a cartridge you plug in. It refuses neon-on-black cyberpunk, glow halos, glass and gradient text; depth comes only from hard offset shadows and physical parts.
OWN-WORLD: Palette unchanged: pink #ff007f, blue #0070ff, cyan #00f3ff, yellow #ffee00 as coin accent, plum ground #180917 (dark default) with #fff5f9 paper in light. Parts: chamfered top-right corner, 3px outline, hard offset shadow, label sticker, edge-connector pin strip, CRT-bezel window for media, segmented HUD bars. Type: Chakra Petch display/labels, Barlow body, Noto Sans JP fallback, Press Start 2P only for scores and counters.
STORY: A pantcake lands, sees at once that this is ShuraHiwa's community arcade, picks a cartridge (play, watch, chat, post) in one tap, in their own language.
FIRST VIEWPORT: Slot-bar nav with logo plate, links as cartridge tabs and language switch; hero is a flat drenched pink field with the stream video inside a CRT bezel on the right, huge display title left, one primary press button (games) and one secondary (media); status strip with live stream state below.
FORM: Arcade cartridge system, user-pinned (seed: none (unavailable)).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
